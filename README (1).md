Sitio web de **Marín Digital**, una oferta de servicios que combina desarrollo de páginas web, asesoría personalizada de calistenia y street workout, y marketing digital.

**Sitio en producción:** [abd-ship.github.io/marin-digital](https://abd-ship.github.io/marin-digital/)

---

## Servicios

| Servicio | Descripción |
|---|---|
| **Páginas web** | Landing pages responsive en tres niveles: Básica, Estándar y Premium. |
| **Calistenia y street workout** | Planes personalizados por nivel (Principiante, Intermedio, Avanzado) con evaluación inicial y seguimiento. |
| **Marketing digital** | Diagnóstico, estrategia de contenido y campañas en redes en tres niveles: Básico, Estándar y Premium. |

## Funcionalidades

- **Navegación directa:** desde el inicio, cada servicio lleva a su sección de precios.
- **Proceso de trabajo:** cuatro etapas, desde la reunión inicial hasta la entrega y el seguimiento.
- **Recomendación personalizada:** el usuario indica los servicios que necesita, su nivel, su presupuesto aproximado y el servicio de interés, y recibe una sugerencia de plan.
- **Formulario de contacto:** las solicitudes se envían por correo mediante [Formspree](https://formspree.io).
- **Diseño responsive:** adaptado a celular, tableta y computadora.

## Tecnologías

| Capa | Tecnología | Uso |
|---|---|---|
| Estructura | HTML5 | Contenido y secciones |
| Estilos | CSS3 | Diseño, tipografía y adaptación a pantallas |
| Interacción | JavaScript | Recomendación y envío del formulario |
| Tipografía | Google Fonts | Fraunces y Plus Jakarta Sans |
| Formularios | Formspree | Recepción de solicitudes |
| Publicación | GitHub Pages | Hosting del sitio estático |

**En desarrollo:** backend con Node.js y Express, base de datos con MongoDB Atlas, panel de administración con autenticación e integración de inteligencia artificial.

## Ejecución local

El sitio es estático y no requiere instalación:

```bash
git clone https://github.com/abd-ship/marin-digital.git
cd marin-digital
```

Después abre `index.html` en tu navegador.
